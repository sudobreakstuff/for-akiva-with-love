# For Akiva, With Love 🌙

An enchanted forest garden of memories for Akiva.

## Before sending to Akiva on June 26

1. **Add photos** — Put 14 photos in `assets/photos/` named `1.jpg` through `14.jpg` (one for each memory)

2. **Add the song** — Download "Mirrors" by Justin Timberlake and place it at `assets/audio/mirrors.mp3`

3. **Edit messages (optional)** — Open `index.html` and find the `FLOWERS` array (around line 300) to personalize each memory message

4. **Test locally** — Open `index.html` in a browser. Since audio/photos are local files, you may need to serve it: `python3 -m http.server` then visit `http://localhost:8000`

## Live URL

Once deployed via GitHub Pages, the URL will be: `https://[your-username].github.io/for-akiva-with-love`
